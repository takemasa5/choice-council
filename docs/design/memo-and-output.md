# メモと終了出力

## セッションメモ

セッションメモは、リアルタイムに細かく更新しない。フェーズ区切り、または重要な整理が終わったタイミングで更新する。`group_chat` では、ファシリテーターが判断軸、選択肢、対立点、未確認事項を整理した場合だけ更新する。

更新時は、画面上に「メモを更新しました」と軽く表示する。

グループチャット開始時のセッションメモは保持する。ユーザーが `group_chat` から `deliberation` へ戻る場合、チャット履歴とチャット中のメモ更新を破棄し、この開始時点のメモへ戻す。

セッションメモには、次の内容を含める。

- 相談テーマ。
- 整理した事実。
- ユーザーが重視したこと。
- 不安や懸念。
- 検討した選択肢。
- 判断軸。
- 専門家コメントの要点。
- 意見が割れた点。
- 未確認事項。
- 次アクション候補。

デスクトップでは右側パネル、スマートフォンではセッションメモ引き出しに、上記の全項目を表示する。メモが更新された場合は「メモを更新しました」と通知する。

## 終了状態

セッションは、最終結論を出さなくても終了できる。以下のいずれかに着地すればよい。

| 終了状態             | 内容                                   |
| -------------------- | -------------------------------------- |
| 暫定結論             | 現時点では特定の方向がよさそう         |
| 判断保留             | 重要な情報が足りないため、まだ決めない |
| 追加調査待ち         | 調べるべきことが明確になった           |
| 家族・関係者相談待ち | 本人、配偶者、親などへの確認が必要     |
| 実行計画             | まず何をするかまで決まった             |

## Markdown 終了メモ

セッション終了時に、Markdown 形式の意思決定メモをダウンロード可能にする。終了前にユーザーは、暫定結論、判断保留、追加調査待ち、家族・関係者相談待ち、実行計画のいずれかを終了状態として選ぶ。終了状態を確定したら、アプリは終了メモ生成を自動開始する。

生成に失敗した場合はグループチャットへ戻り、終了状態を未選択へ戻す。ユーザーは会話を続けるか、終了状態を選び直せる。

アプリ側では過去メモを永続保存しない。次回セッションで過去メモを使う場合は、ユーザーが Markdown ファイルを添付する。

将来的には、HTML または PDF 出力にも対応する。

Markdown 構成:

```markdown
# 意思決定メモ

## 相談テーマ

## 現時点の状態

## 重視した価値観

## 整理した事実

## 検討した選択肢

## 主な判断軸

## 専門家コメント要約

## 意見が割れた点

## 未確認事項

## 次アクション

## セッションログ要約
```

`セッションログ要約` には、グループチャットで重要だった論点の展開、ユーザーの意思表示、終了状態に至った経緯を含める。発言全文は出力しない。

## 解消済み

次の事項は初期設定で方針を決定済み。

- 技術スタック: TypeScript + React + Node.js + Express。
- 使用する LLM API: OpenAI API。
- M1 のプロンプト範囲: 契約定義のみ。文言調整と品質検証は M2 以降。
- フェーズ遷移: 通常操作として前フェーズへ戻れる。
- 前フェーズへ戻る場合: 確認後、戻り先以降の生成結果を現在セッションから完全に破棄する。
- M1 の schema 同期範囲: `docs/` の詳細仕様まで。Zod schema 実装は実装タスクとして扱う。
- JSON schema の厳密さ: 未知フィールド不可、必須文字列と配列要素の空文字不可。

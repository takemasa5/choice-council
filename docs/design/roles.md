# ロール設計

## ファシリテーター

ファシリテーターは、セッションを主導する進行役である。専門家同士を自由に会話させるのではなく、現在フェーズに必要な専門家だけを指名する。

主な責務は以下のとおり。

- 現在フェーズの管理。
- 論点設定。
- 専門家の招集案作成。
- 専門家の発言管理。
- 専門家コメントの整理。
- ユーザーへの質問。
- 対立軸の整理。
- セッションメモ更新の指示。
- 終了メモへの着地。

## グループチャットでの進行

`group_chat` では、ファシリテーターが毎回1人だけを指名して会話を進める。指名時には、誰を選んだか、選んだ理由、回答してほしい質問をチャット上に表示する。

指名先は、直前の発言への関連が最も強い専門家、対立する見解を持つ専門家、またはユーザーとする。専門家の連続回答は最大2回であり、2回の専門家回答の後は必ずユーザーを指名する。ただし、ユーザーの発言が最も関連する、または最も対立する場合は、専門家1回の回答後にユーザーを指名できる。

専門家が連続して回答する場合は、確定済み専門家が2人以上なら直前の専門家とは別の専門家を指名する。指名質問では直前の主張との関係を示し、回答者に賛成・留保・反論とその根拠または成立条件を求める。これにより、専門家が独立したコメントを並べるのではなく、異なる観点から論点を検討するディベートとして進行する。

ファシリテーターの進行・要約・指名理由は、参加者の回答回数に数えない。ユーザーが「そのまま意見交換を続けて」を選んだ場合は、ユーザーが現在は聞き役を選んだ意思表示として扱い、回答1回に数える。

判断軸、選択肢、対立点、未確認事項は、`direction` の独立フェーズではなく、グループチャット中に必要な時点で整理する。重要な整理が生じた場合だけ、セッションメモを更新する。

## 専門家ロール

専門家は、人間的なキャラクターではなく、役割・観点として表示する。

例:

| 専門家                     | 重視する観点                           |
| -------------------------- | -------------------------------------- |
| 教育方針アドバイザー       | 子どもの納得感、学校との相性、学習負担 |
| 家計・生活負担アドバイザー | 費用、送迎、親の時間、継続可能性       |
| 当事者視点アドバイザー     | 本人の気持ち、家庭内の摩擦、主体性     |

専門家の数は固定しない。相談テーマに応じて必要な人数を招集する。ただし、表示上の情報量はファシリテーターが制御する。

## 専門家選定

専門家選定フェーズでは、ファシリテーターが専門家案を提示する。

候補は、相談に固有の判断軸について競合する価値・制約を持つロールを優先する。たとえば「家庭の継続負担を抑える」と「本人の意欲を最大化する」は比較できるが、人格的に対立する人物像は作らない。競合だけで論点が不足する場合は、安全性・制度・実行可能性などの補完観点を追加する。

ユーザーは次の操作を行える。

- このまま進める。
- 専門家を追加する。
- 専門家を外す。
- 専門家を入れ替える。
- おまかせで進める。

## 専門家コメント

専門家コメントは、専門家ごとに個別の LLM 呼び出しで生成する。

初回コメントは並列生成を想定する。各コメントは、案名、内容、利点、犠牲にする点、成立条件を持つ具体的な案を1つだけ提示する。案は専門家ロールではなく、ユーザーが後続の検討対象として選ぶ単位である。

通常表示では、各専門家コメントを 300〜400 字程度に整える。必要に応じて、元コメントや詳細を展開できるようにする。

すべての専門家が毎回発言する必要はない。初回コメント後は、ファシリテーターが必要な専門家だけを1人ずつ指名する。

初回コメント後、ユーザーは次のいずれかを選ぶ。

- 1案を深掘りする。
- ちょうど2案を比較する。
- まだ案を選ばず、比較軸を整理する。

ファシリテーターはこの選択を以降の意見交換の起点として保持する。深掘りでは、`participantId` で一意に識別した提案者に根拠の擁護を求め、他の専門家に具体的な反論・代替・成立条件を求める。比較では2案のトレードオフを扱い、保留では案を早期に脱落させず比較軸を整理する。

## 未発言の専門家への確認

重要フェーズでは、ユーザーが「未発言の専門家にも確認する」ボタンを押せるようにする。

この場合、未発言の専門家には次の問いだけを投げる。

```text
このフェーズで見落としている重要観点はありますか？
```

回答は各専門家 100〜200 字程度に抑える。重要な指摘のみ、ファシリテーターが次の論点に昇格させる。

## 意見が割れた場合

専門家コメントが食い違った場合、ファシリテーターはすぐに結論を出さない。まず、対立している判断軸として整理する。

例:

```text
今回の分岐点は、「家庭の継続負担」と「本人の意欲」のどちらを重く見るかです。
```

必要に応じて、ユーザーに選択肢つきで重みづけを確認する。

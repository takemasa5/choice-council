# セッションメモ更新プロンプト

## 役割

フェーズ区切り、または重要な整理が終わったタイミングでセッションメモを更新する。

## 方針

- リアルタイムに細かく更新しない。
- 相談テーマ、整理した事実、重視したこと、不安や懸念を明確にする。
- 検討した選択肢、判断軸、専門家コメントの要点を整理する。
- 意見が割れた点を、対立している判断軸として残す。
- 調査が必要な事項は未確認事項として残す。
- 次アクション候補を具体的にする。
- 出力は `docs/api/schemas.md` のセッションメモ schema に従う。

## 入力文脈

状態: `決定`

- 相談内容。
- 現在フェーズ。
- 既存のセッションメモ。
- 新しく追加されたファシリテーター整理。
- 新しく追加された専門家コメント。
- ユーザーの回答または操作。

## 出力契約

状態: `決定`

出力は `docs/api/schemas.md#セッションメモ` に従う。既存メモを丸ごと置き換えるのではなく、フェーズ区切りで必要な更新を反映した最新版として返す。

# 調査の扱い

## MVP での扱い

プロトタイプでは外部調査を実装しない。

ただし、前提整理の段階で、ファシリテーターは外部調査が役立つ可能性を確認する。

選択肢例:

- 必要に応じて調査する。
- まず調査してから議論する。
- 調査なしで整理する。
- その他。

ユーザーが議論中に「調べてほしい」と割り込むケースも想定する。

外部調査が必要な場合、プロトタイプでは「調査が必要な未確認事項」としてセッションメモに残す。

## 将来の調査メモ

将来的には、調査結果を専門家コメントと混ぜず、出典つきの「調査メモ」として別枠表示する。

調査メモは、次の項目を持つ。

| 項目 | 内容 |
|---|---|
| 調査テーマ | 何を調べたか |
| 要点 | 意思決定に関係する事実 |
| 出典 | 参照元のページ名、サービス名 |
| 取得日 | 情報を確認した日 |
| 確からしさ | 高、中、低 |
| 注意点 | 情報が古い、口コミ依存、条件差がある、など |

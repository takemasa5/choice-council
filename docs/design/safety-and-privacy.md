# ガードレールとプライバシー

## ガードレール

MVP では、次の領域に対して進行上のガードレールを設ける。

| 領域             | 扱い                                     |
| ---------------- | ---------------------------------------- |
| 医療・健康       | 診断や治療方針を断定しない               |
| 法律・相続       | 一般的な論点整理や相談準備に留める       |
| 投資・金融       | 売買判断や断定的助言をしない             |
| 生命・安全       | 緊急性がある場合は安全確保を優先する     |
| 子ども・虐待・DV | 安全確保と適切な相談先への接続を優先する |

ただし、画面上に毎回「専門家相談の代替ではありません」といった警告を出すことはしない。

該当テーマでは、ファシリテーターが自然にセッションゴールを切り替える。

例:

```text
このテーマは制度や個別条件で結論が変わりやすいため、今回は「判断材料の整理」と「確認すべき質問リストの作成」まで進めます。
```

## 保存とプライバシー

ログインは不要とする。

セッション中の内容はブラウザ内に自動一時保存し、リロード時に復元できるようにする。グループチャットの発言履歴、累積会話要約、セッションメモも同じ一時保存の対象とする。

個人的な相談が多いため、画面上に「この端末に一時保存されます」と明示し、削除ボタンを用意する。

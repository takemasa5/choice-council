# Markdown 出力プロンプト

## 役割

セッション終了時に、ユーザーが後で見返せる意思決定メモを Markdown 形式で生成する。

## 方針

- 最終結論が出ていなくても終了できる。
- 暫定結論、判断保留、追加調査待ち、家族・関係者相談待ち、実行計画のいずれかに着地させる。
- 未確認事項と次アクションを明確にする。
- 専門家コメントは要点だけに整理する。
- 断定できないことを断定しない。

## Markdown 構成

```markdown
# 意思決定メモ

## 相談テーマ

## 現時点の状態

## 重視した価値観

## 整理した事実

## 検討した選択肢

## 主な判断軸

## 専門家コメント要約

## 意見が割れた点

## 未確認事項

## 次アクション

## セッションログ要約
```

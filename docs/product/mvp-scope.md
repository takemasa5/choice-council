# MVP スコープ

## 含める機能

| 区分         | 内容                                                           |
| ------------ | -------------------------------------------------------------- |
| 相談開始     | 自由入力による相談開始、任意の補助入力欄                       |
| 進行管理     | フェーズ表示、ファシリテーターによる進行                       |
| 専門家ロール | 相談内容に応じた専門家提案、追加、削除、入れ替え               |
| コメント生成 | 専門家ごとの個別コメント生成、ファシリテーターによる整理       |
| メモ         | フェーズ区切りでのセッションメモ更新、終了メモの Markdown 出力 |
| 割り込み     | 「ちょっと待って」ボタンによるユーザー割り込み                 |
| 保存         | ログインなし、ブラウザ内の一時保存                             |
| 安全対策     | 高リスク領域に対する進行上のガードレール                       |

## 含めない機能

| 区分       | 内容                                     |
| ---------- | ---------------------------------------- |
| アカウント | ユーザー登録、ログイン                   |
| 履歴管理   | アプリ側での永続的な履歴保存             |
| 外部連携   | 外部 Web 調査、複数ベンダー LLM の実接続 |
| 出力       | PDF/HTML 出力                            |
| UI         | 複雑なテンプレート選択                   |
| 評価       | 詳細な定量評価指標                       |

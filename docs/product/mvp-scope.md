# MVP スコープ

## 含める機能

| 区分         | 内容                                                                                 |
| ------------ | ------------------------------------------------------------------------------------ |
| 相談開始     | 自由入力による相談開始、任意の補助入力欄                                             |
| 進行管理     | フェーズ表示、ファシリテーターによる進行                                             |
| 専門家ロール | 相談内容に応じた専門家提案、追加、削除、入れ替え                                     |
| コメント生成 | 専門家ごとの初回コメント生成、ファシリテーターによるグループチャット進行             |
| メモ         | 重要な整理時のセッションメモ更新、グループチャット要約を含む終了メモの Markdown 出力 |
| 保存         | ログインなし、ブラウザ内の一時保存                                                   |
| 安全対策     | 高リスク領域に対する進行上のガードレール                                             |
| LLM選択      | 環境変数による OpenAI API または Gemini API のアプリ全体切替                         |

## 含めない機能

| 区分       | 内容                                             |
| ---------- | ------------------------------------------------ |
| アカウント | ユーザー登録、ログイン                           |
| 履歴管理   | アプリ側での永続的な履歴保存                     |
| 外部連携   | 外部 Web 調査、ロールごとの複数ベンダー LLM 接続 |
| 出力       | PDF/HTML 出力                                    |
| UI         | 複雑なテンプレート選択                           |
| 評価       | 詳細な定量評価指標                               |

# Prompts

このディレクトリでは、OpenAI API または Gemini API へ渡すプロンプトを呼び出し単位で管理する。プロンプトの内容はプロバイダーに依存させず、バックエンドのLLMプロバイダー層で各SDKのリクエスト形式へ変換する。

MVPでは以下を分ける。

- `facilitator.md`
- `expert.md`
- `session-memo.md`
- `final-markdown.md`

各プロンプトは `docs/api/schemas.md` の構造化出力に従う。

## M1 の対象範囲

状態: `決定`

M1 ではプロンプト本文の品質検証までは行わない。M1 で定義するのは、各呼び出しのプロンプト契約である。

プロンプト契約には次を含める。

- 入力として渡す文脈。
- 従う JSON schema。
- その呼び出しが担当する責務。
- やってはいけないこと。

文言調整、few-shot 追加、モデルパラメータ調整、実出力の品質評価は M2 以降で扱う。

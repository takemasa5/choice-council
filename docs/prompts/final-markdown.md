# Markdown 出力プロンプト

## 役割

セッション終了時に、ユーザーが後で見返せる意思決定メモを Markdown 形式で生成する。

## 方針

- 最終結論が出ていなくても終了できる。
- 暫定結論、判断保留、追加調査待ち、家族・関係者相談待ち、実行計画のいずれかに着地させる。
- 未確認事項と次アクションを明確にする。
- 専門家コメントは要点だけに整理する。
- セッションログ要約には、重要な論点の展開、ユーザーの意思表示、終了状態に至った経緯を含める。発言全文を列挙しない。
- 断定できないことを断定しない。

## 入力文脈

状態: `決定`

- 相談内容。
- 最終版のセッションメモ。
- 採用された専門家コメント要約。
- 意見が割れた点。
- 未確認事項。
- 次アクション。
- ユーザーが選択した終了状態。
- グループチャットの累積要約と直近の発言。

## 出力契約

状態: `決定`

出力は `docs/api/schemas.md#Markdown 終了メモ` に従う。Markdown の見出し構成は下記の構成に合わせる。全文は 3000 字以内とし、各セクションは簡潔にする。見出し、段落、順不同リストだけで表現する。

## Markdown 構成

```markdown
# 意思決定メモ

## 相談テーマ

## 現時点の状態

## 重視した価値観

## 整理した事実

## 検討した選択肢

## 主な判断軸

## 専門家コメント要約

## 意見が割れた点

## 未確認事項

## 次アクション

## セッションログ要約
```

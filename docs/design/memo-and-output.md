# メモと終了出力

## セッションメモ

セッションメモは、リアルタイムに細かく更新しない。フェーズ区切り、または重要な整理が終わったタイミングで更新する。

更新時は、画面上に「メモを更新しました」と軽く表示する。

セッションメモには、次の内容を含める。

- 相談テーマ。
- 整理した事実。
- ユーザーが重視したこと。
- 不安や懸念。
- 検討した選択肢。
- 判断軸。
- 専門家コメントの要点。
- 意見が割れた点。
- 未確認事項。
- 次アクション候補。

## 終了状態

セッションは、最終結論を出さなくても終了できる。以下のいずれかに着地すればよい。

| 終了状態 | 内容 |
|---|---|
| 暫定結論 | 現時点では特定の方向がよさそう |
| 判断保留 | 重要な情報が足りないため、まだ決めない |
| 追加調査待ち | 調べるべきことが明確になった |
| 家族・関係者相談待ち | 本人、配偶者、親などへの確認が必要 |
| 実行計画 | まず何をするかまで決まった |

## Markdown 終了メモ

セッション終了時に、Markdown 形式の意思決定メモをダウンロード可能にする。

アプリ側では過去メモを永続保存しない。次回セッションで過去メモを使う場合は、ユーザーが Markdown ファイルを添付する。

将来的には、HTML または PDF 出力にも対応する。

Markdown 構成:

```markdown
# 意思決定メモ

## 相談テーマ

## 現時点の状態

## 重視した価値観

## 整理した事実

## 検討した選択肢

## 主な判断軸

## 専門家コメント要約

## 意見が割れた点

## 未確認事項

## 次アクション

## セッションログ要約
```
